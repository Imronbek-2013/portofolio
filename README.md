# Imronbek Portfolio

React and Vite portfolio website for Abdullayev Imronbek.

## Local development

```bash
npm ci
npm run dev
```

Before publishing, run the same checks used by the deployment:

```bash
npm run lint
npm run build
```

## Deployment

The project is configured for Vercel. Import the GitHub repository and keep the default Vite settings, or use:

- Install command: `npm ci`
- Build command: `npm run build`
- Output directory: `dist`
